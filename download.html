VS Code 로컬 실행 가이드
1
위 버튼으로 ZIP 다운로드 후 원하는 폴더에 압축 해제
2
VS Code에서 File → Open Folder 로 해제된 폴더 열기
3
Extensions에서 Live Server 설치 (Ritwick Dey 작성)
4
index.html 우클릭 → Open with Live Server
5
브라우저 http://127.0.0.1:5500 자동 오픈 🎉
모바일 테스트: 같은 Wi-Fi에서 http://[PC-IP]:5500 접속
※ 카메라는 HTTPS 또는 localhost 에서만 작동합니다

Google Play 등록 가이드 (TWA)
1
아이콘 생성: icons/generate-icons.html 열기 → Generate All Icons 클릭 → 72·96·128·144·192·512px PNG 자동 생성
2
HTTPS 배포: Netlify / Vercel 배포 (netlify.toml, vercel.json 포함)
3
assetlinks.json: Digital Asset Links 생성 후 /.well-known/assetlinks.json 배포
4
Bubblewrap CLI: npm i -g @bubblewrap/cli → bubblewrap init --manifest https://[배포URL]/manifest.json
5
APK 빌드: bubblewrap build → app-release-signed.apk 생성 후 Google Play Console 업로드
